# GP-Games

## last-partner-standing/

A single-page vanilla JS game with no dependencies. The only build step is concatenation.

- Edit the files in `src/`, then run `sh last-partner-standing/build.sh`. It writes three HTML files and `build.txt`, all committed. Never hand-edit them.
  - `last-partner-standing.html` is the Claude Artifact source. It has no doctype, head or body tags, because the Artifact publish step adds them.
  - `last-partner-standing-play.html` is the standalone copy, with doctype, charset and viewport. Players open this one.
  - `last-partner-standing-trailer.html` is the trailer page (see The trailer below). It uses `src/c-data.js` and `src/c3-art.js`, so rebuild it when the drawings, the cast or the practices change.
- Check the layout on phones as well as desktop. Below 640px the month plan gets a fixed Start bar, the staff list starts collapsed and the mini-games hide the meters. On touch screens the keyboard hints are hidden.
- After changing numbers, events or the engine, run the balance check: `node last-partner-standing/tools/simulate.mjs 200` (optional arguments: `suburb|town|city|all` and `random|smart|both`). It plays whole years headlessly and reports survival, endings, profit share and final meters.
- Deploy: the Vercel project `gp-games` (team john-g-projects) is linked to this GitHub repo. A push to `main` deploys to production at https://gp-games.vercel.app. A push to any other branch builds a preview, which can be promoted to production from Vercel. `vercel deploy --prod --yes` from the repo root still works by hand. Push `main` before the working branch: if the branch is pushed first with the same commit, Vercel may build only the preview and skip production (this happened in September 2026, and the preview couldn't be promoted). Commit the rebuilt HTML, because Vercel doesn't run `build.sh`.
  - `vercel.json` rewrites `/` and `/last-partner-standing` to the playable file, and `/trailer` to the trailer page.
  - `.vercelignore` keeps source, tools and docs out of the deployment.
  - The website is an installable app: `manifest.webmanifest` and the icons (`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, rendered by `tools/og-card.mjs`), and `sw.js`, served at `/sw.js` by a rewrite so it controls the whole site. It fetches the page fresh when online and serves the cached copy offline; it caches the game as `/` and any other page (the trailer) under its own address, so visiting the trailer never replaces the game offline; it never caches the leaderboard, the video or `build.txt`. It registers only on vercel.app over https, not in the Artifact. Bump `CACHE` in `sw.js` if its caching rules change (now `lps-v3`).
  - Updates reach open games: `build.sh` takes a 7-character id from a hash of the sources, stamps it into the page as `BUILD` and writes `last-partner-standing/build.txt` (served with `no-cache`). On the website, an open game fetches `build.txt` about 4 seconds after opening, whenever it comes back into view (at most every 5 minutes) and every half hour, and when it differs from `BUILD` shows a banner: "A new version of the game is ready" with Reload (`checkUpdate()`, `showUpdate()` in `i-mini.js`). The menu shows the version and has "Check for a new version". To see what the live site is running, compare https://gp-games.vercel.app/last-partner-standing/build.txt with `last-partner-standing/build.txt` on main.
  - Rebuild before deploying.
  - Link previews: `build.sh` writes Open Graph and `twitter:card` (`summary_large_image`) tags into the playable file, plus the favicon and `apple-touch-icon.png`, both from `src/icon.svg` (a GP with a stethoscope standing on the logo's yellow line). The preview image is `last-partner-standing/og.png` (1200×630), rendered from `tools/og-card.html` by `node last-partner-standing/tools/og-card.mjs` (needs Playwright; set `CHROMIUM` to a Chromium path). `og:url` is https://last-partner-standing.vercel.app and the image URL points at gp-games. Re-render and commit the PNGs if the card changes.
  - https://last-partner-standing.vercel.app (the Vercel project `last-partner-standing`) is a proxy. It holds only `vercel-proxy/last-partner-standing/vercel.json`, which rewrites every request to https://gp-games.vercel.app. So it always serves whatever `gp-games` is serving, and a push to `main` updates both addresses. Don't deploy the game to that project. Only redeploy it if the proxy file changes (see `vercel-proxy/README.md`).
- Leaderboard database (endless mode added the `months` column, migration `lps_scores_months`; the board has a "Longest serving" tab, and runs that end after year one can post their months from the game-over screen): the Supabase project `rttvlxawjidhneljhglk` (organisation GP Games, region eu-west-1), applied as the migration `lps_scores_leaderboard`. `last-partner-standing/supabase/lps_scores.sql` creates the table, row-level security (anyone can read and insert; nobody can update or delete), sanity checks on values, a server-set timestamp and a limit of 30 posts a minute. Scores are computed in the browser, so they can be faked. Names pass a word filter twice: `nameOk()` in `h3-board.js` and `lps_name_ok()` in the database (migration `lps_scores_name_filter`). Keep the two word lists the same. Ambiguous words only match as whole words, so real surnames like Wankhede, Nazim and Draper get through. To remove a name by hand, run `delete from public.lps_scores where id = …` in the Supabase SQL editor. The title screen has a Privacy explainer.
- Save games (`lps-save-v2`), best scores (`lps-best-v1`) and the Partners' Board (`lps-board-v1`) live in `localStorage`. A save made at a year end can be resumed, so the player can still carry on into the next year. Every access is wrapped in try/catch. Bump the save key if the state shape changes.
- The trailer: a 75-second film about the game, drawn live in the browser with the game's own art, at https://gp-games.vercel.app/trailer (and `/trailer` on last-partner-standing.vercel.app). The same frames are rendered to `last-partner-standing/trailer.mp4`, which the page offers as a download on the website.
  - Source in `last-partner-standing/trailer/`: `STORYBOARD.md` (the scenes, timings, continuity and the only facts the film may use, with their sources), `t-head.html` (title, fonts, CSS), `t-body.html` (the player page), `t-engine.js` (the timeline and helpers), `scenes/s1-deed.js` to `scenes/s7-endcard.js` (one file per scene, played in name order) and `t-boot.js` (controls, chapters, scaling). `assemble.sh` joins them after `src/c-data.js` and `src/c3-art.js`; `build.sh` calls it for `last-partner-standing-trailer.html`, and `assemble.sh --artifact OUT` writes a Claude Artifact copy.
  - Every frame is a pure function of the time: a scene's `update(lt)` sets everything from `lt` alone (no `Date`, `Math.random`, CSS animations, transitions or timers), so the page can play, scrub backwards and be captured frame by frame. `TR.facade()` draws the game's `facadeSVG` from a faked state (`TR.world()`), `TR.street()` paints the night street around it, `TR.cardHTML()`, `TR.hud()` and `TR.brass()` draw the game's card, HUD strip and brass plate. The film has a fixed look; the page around it follows the game's light and dark tokens.
  - `node last-partner-standing/tools/trailer-render.mjs` renders it with Playwright: `--check` (every frame at 10 fps, forwards and backwards, page errors and the slowest frame), `--sheet` contact sheets, `--at` frames, `--video trailer.mp4 --scale 1.5` (1920×1080 H.264 at CRF 25, about 9 MB, with a silent AAC track; needs ffmpeg with libx264, or `pip install imageio-ffmpeg`) and `--poster T file.png`. `--only s3` assembles one scene on its own, and `--page` renders the built page. Web fonts are fetched with curl into a temporary cache, so it works behind a proxy that Chromium doesn't trust. The brass plate and the front's sign use Georgia, or Gelasio (made to Georgia's metrics) where Georgia isn't installed, so renders on Linux match.
  - Social cuts: `--frame square` (1080×1080, for X) and `--frame portrait` (1080×1350, for LinkedIn) put the film edge to edge between a headline ("How long can you last as a GP partner?") and the web address, with a progress bar. They aren't committed; render them when needed, for example `--page last-partner-standing/last-partner-standing-trailer.html --frame square --video trailer-x.mp4 --poster 74.5 cover-x.png`.
  - The page shows `TR.POSTER` (6.9 s: the deed line over the lit front) before it plays. `trailer-poster.png`, the link preview, is the end card at 74.5 s, 1280×720.
  - After changing the trailer or the art it uses: rebuild, re-render `trailer.mp4` (`--video last-partner-standing/trailer.mp4 --scale 1.5`) and `trailer-poster.png` (`--poster 74.5 last-partner-standing/trailer-poster.png`), and commit all three.

### src files

`build.sh` joins these into one script, in this order (`c3-art.js` comes after `c2-minidata.js`, `f5-events7.js` after `f4-events6.js`, `f6-events8.js` after `f5-events7.js`, `f7-events9.js` after `f6-events8.js`, and `f8-events10.js` after `f7-events9.js`):

- `a-head.html`: title, the Google Fonts link and all the CSS. Colours are tokens on `:root`, overridden for dark mode by both the `prefers-color-scheme` media query and `[data-theme]`.
- `c-data.js`: the sourced 2026/27 constants (`P`), practices, staff roles with costs that include employer NI and pension, projects, the cast, meter icons, headlines, `SOURCES` and `GLOSSARY`.
- `c2-minidata.js`: Docman Dash, 8am Rush and Walkround items.
- `c3-art.js`: everything drawn, as SVG in code. Profile silhouettes (`LOOKS` for the cast, `PLAYER_LOOKS` and `PLAYER_COLOURS` for the player, `SIL_OBJ` for objects such as the bank or Gerald's bowl), built by `portraitSVG(key)` from a head, a body, a hair shape and accessories. Also the surgery front (`facadeSVG`, `brassPlate`), the year brief (`briefHTML`), the Partners' Board (`partnersBoardHTML`) and the share picture (`shareSVG`, `openShareImage`). The style follows No. 10: Full Confidence: flat dark silhouettes on cream tiles, lamp-lit windows at night. Our own drawings and palette, not theirs.
- `d-events1.js`: story arcs (scheduled): partners, CQC, QOF year end.
- `e-events2.js`: patient, team and wellbeing cards.
- `f-events3.js`: money, safety and systems cards. These include the clinical system outage (paper notes, handwritten FP10s, no records; a continuity kit sets `flags.bcp` and softens later outages), ICB-pushed Windows updates, and medicine shortages (Medicine Supply Notifications and Serious Shortage Protocols). Also `hcq_screening`: a patient on hydroxychloroquine under private shared care whose rheumatologist moved abroad, so the annual review and the eye screening due after five years never happened (national shared care protocol `S85`, RCOphth `S86`). It spells out the risks of taking on shared care from a private specialist: it's voluntary, the specialist has no NHS contract (so nothing obliges them to keep reviewing or to say when they stop, and there's no NHS clinic to hand back to), and whoever signs the prescription is responsible (GMC `S102`, BMA `S103`, `S104`, including the 2025 LMC conference policy). One choice searches for every such patient and adopts a no-private-shared-care policy, which costs patients who then pay privately.
- `f2-events4.js`: the real calendar (contract day, pay awards, patient survey, headline, flu, winter), real-rule cards, crisis cards and the other endings.
- `f3-events5.js`: CQC myths and oddities from CQC's own GP mythbusters (Gavin the consultant, Gerald the fish tank, furosemide, curtains, knitted ducks, carpet, DBS), the draft-report challenge and the Walkround mini-game card. `cqcPrep(n)` banks credit that `runCQC` adds to Safe and, halved, to Well-led.
- `f5-events7.js`: the long haul: cards gated by `pmin` (see Pressure below), such as the AI scribe, the ICB merger, Sandra retiring, the Ombudsman, the locum chambers, Parkside and Apex coming back, plus the three-year review (`review_3y`, `review3y()`).
- `f6-events8.js`: the long haul, part two (29 cards, mostly for year 2 on or under pressure). Money tools: sale and leaseback (`p_leaseback`), renting rooms, a service bid, a salaried GP buying in as Priya (`p_buyin`), a GP claimed through the PCN budget (`p_arrs_gp`, `S.arrsGP`, `ARRS_GP_CLAIM`: ARRS reimburses actual salary plus on-costs up to £152,900 a year full time, so our six-session GP is claimed at their real cost, about £82k, and the practice doesn't pay their salary) and a shared back office. Stories that carry across years: Nadia back from Perth, Alan as a locum, Mrs Higgins at 90 and then her bench, Gerald's death and Gerald (II), Kayleigh training as a nursing associate, the Station Road patients coming back as uncoded reviews. Plus the grind: partners burning out or retiring, list dispersal, a new clinical system, OPEL 4.
- `f7-events9.js`: 31 cards for any year, mostly the paperwork around the edges. `letter_dump` (once, tagged real): the hospital finds two years of clinic letters were never sent, and 4,212 arrive in Docman at once. Its explainer cites the NHS Shared Business Services backlog (about 709,000 items, 2011–2016, NAO `S95`) and trust IT failures reported by Pulse (`S96`, `S97`). Real rules: a subject access request (ICO, `S87`), a patient who shouldn't be driving (DVLA and GMC, `S88`, `S89`), firearms medical forms (`S90`), the duty of candour (`S91`), damp and mould letters and Awaab's Law (`S92`), Freedom to Speak Up (`S93`) and the appointment data league table (`S94`). Plus the week going wrong (fit notes, wasps, a power cut and the vaccine fridge, bounced referrals, a locum no-show, a phishing email, forged prescriptions, snow, no cleaner, a city interpreter card) and five `pmin` cards (a new CQC framework, the PCN splitting, a tired near miss, a viral video of a receptionist, an appraiser job).
- `f8-events10.js`: the contract explained, six cards for year one in the suburb and the town (see Contract explainers below): `teach_money` (the global sum and weighting), `teach_qof`, `teach_lcs` (enhanced services: national ones like flu, and the local LES or LCS an ICB buys and can end), `teach_arrs`, `teach_drawings` (drawings, the pension and Self Assessment) and `teach_partner` (why be a partner). Also `lcs_cut`, a real card for every practice (see Local services can end below). Sources `S2`, `S3`, `S4`, `S8`, `S13`, `S21` to `S23`, `S27`, `S72`, `S83`, `S84` and `S99` to `S101`.
- `f4-events6.js`: demand from outside the building: the PSA rush after a celebrity diagnosis, testosterone requests after a menopause documentary (with an option to set up a PCN women's health hub), the ICB closing community dermatology, and patients on hospital waiting lists asking for expedite letters. The Mounjaro card (news of new guidance, no LCS) is in `e-events2.js`.
- `g-engine.js`: state `S`, month flow, the money model (`calc`), where meters are heading (`targets`), state-driven incidents and delayed consequences (`monthEnd`).
- `g2-endings.js`: CQC ratings, game overs, other endings, year-end accounts and the partner's own tax and pension (`personalTax`), and saving.
- `h-ui.js`: helpers (`explain()` for expandable explainers, `srcLinks()`), HUD, title, month plan and cards.
- `h2-screens.js`: month report, endings, overlays (how to play, glossary, sources) and input handling via event delegation on `data-act`.
- `h3-board.js`: the shared leaderboard. It reads and posts scores in the Supabase table `lps_scores` through its REST API, using the project URL and publishable key in `BOARD`. With `BOARD.url` empty, it stays hidden. It shows on the year-end screen, the title screen and in the menu. Inside a Claude Artifact the network is blocked, so it points players to the website.
- `i-mini.js`: the three mini-games (Docman Dash, The 8am Rush, The Walkround), then boot.

### How consequences work

- **Meters drift.** Each month every meter moves a fixed fraction (`DRIFT`) toward a target set by the practice's situation: capacity against demand, the inbox, reception and rooms, pay, hours worked, reputation and winter. `targets()` returns each target with its reasons, which the planner shows in "Where things are heading".
- **One-off effects fade; lasting ones don't.** Plain `fx` values jolt a meter and then drift back. `aim` moves the target itself, permanently or for a while through a `mod` with `aim`.
- **Delayed effects.** `later: [{in, p, fx, note}]` plants a consequence that may land `in` months later with probability `p`. Its `note` appears under "What came of it" in the month report, in "From your earlier choices": `plant()` records the card, the month, the year and the choice that planted it (`S._pick`, set by `resolveChoice`), so each note starts "The fish tank, April: you chose “Leave it. He's a goldfish.”" ("last year" in a later year, "your predecessor chose" after a take-over) and ends with chips for what it changed (`consqHTML()` in `h2-screens.js`). Consequences of the practice's state (`incidents()`, patients leaving, ICB warnings) are plain strings, listed under "From the state of the practice". Seeds must be plain data, not functions, so they survive saving.
- **State-driven incidents.** `incidents()` rolls month-end events from the state, for example a missed result when the inbox is high or a resignation when morale is low. Each note says "Because…".
- **The ICB contract process.** The patients crisis card is a remedial notice (`flags.remedialAt`). If Patients is below 30 a month later, a breach notice follows. Once notice has been served, three month-ends in a row with Patients below the practice's `accessLine` (15 in the city, 10 elsewhere; counted in `flags.lowAccess`) make the ICB terminate the contract (`forceOver = 'patients'`). The month report warns after two.
- **Crises before game over.** A meter at 18 or below, the bank past its overdraft limit, or being the last partner queues a one-off crisis card first.
- **Situational choices.** `ctxFx(fx)` in `g-engine.js` adjusts every choice's effects for the moment, in the engine (`resolveChoice`), the choice badges (`hintFor`) and the simulator's sensible player. A hit to a meter below 30 lands a quarter harder; hits to You and Patients land a quarter harder in winter (`WINTER_MONTHS`) and hits to Team in the summer holidays (`SUMMER_MONTHS`); spending money with the bank past half its overdraft limit also costs You; more inbox on an inbox over 500 costs Safety. Gains to a meter at 75 or more are halved, and gains to one below 30 are worth a third more. The card shows a "Right now:" note with the reasons, and affected choices get a "Costs more right now" badge. Some cards also have state-dependent effects written in (for example `welcome`, `qof_yearend`, `headline`, `thank_you`, `locum_no_show`, `parking`, `student_nurse`, and a bank-staff option on `winter_phones`).
- **Badges for hidden stakes.** `hintFor` reads each choice's `run()` too: a `chance(` roll shows "Gamble", `plant(` or `schedule(` shows "Comes back later", and `addMod(` or an ongoing cost shows "Lasting".
- **The seasons.** `LEAVE` in `c-data.js` takes capacity away for staff annual leave (Easter, school summer holidays, Christmas). `targets()` adds summer holiday pulls on You and Team, a flu-clinic pull on You in September to November, and a slightly softer winter.
- **The summer crunch.** In the suburb and town, `newGame` and `continueYear` schedule `twist_summer` (in `f4-events6.js`) in June, July or August: a salaried GP or a practice nurse resigns with a month's notice (`S.flags.summerGP` picks which; a vacancy is opened). The choices are agency locums (about £3,200 a month for two months), cancelling leave (Team and You) or pausing routine work (Patients and Safety).
- **Other endings.** Setting `S.exit` in a choice (`sold`, `merged`, `salaried`, `emigrated`, `handback`) ends the game after the outcome card.
- **Mergers when money runs out.** The payroll crisis card (`lifeline`) offers a merger with Parkside (70% it goes through, otherwise the bank extends the limit by £20k), and `p_merger_again` comes up, weighted, whenever the bank is past half its overdraft limit.
- **Crisis cards can fail.** The lifeline, the month off, the 5% pay rise and the remedial locums each have an `alt` gamble (15–35%, highest for city locums) where the rescue only half works.
- **Neglect costs money.** In `calc`, vaccination and enhanced-service income is scaled by `serviceF` (capacity against demand, 0.45 to 1.03), and a `cover` cost grows when Team is below 45 or Safety below 35 (sickness cover and incidents). Patients below 35 makes people leave the list each month. A CQC Requires improvement costs £6k and Inadequate £15k.
- **Twists.** `newGame` schedules one late-year twist in months 6–9: `twist_ill` (a partner off sick, chosen by `illPartner()`), `twist_fire` (£38k fire doors) or `twist_flood` (two rooms lost). They are in `f4-events6.js`.
- **Goals and the weekly challenge.** Each year gets one `GOALS` entry (`S.goal`), shown in the HUD; meeting it adds `GOAL_BONUS` (40) to the score. The weekly challenge (`weeklyChallenge()`) seeds `Math.random` from the ISO week (`S.rng`, mulberry32), so everyone that week gets the same goal, twist and luck. It is always the brutal city practice (Canal Street). Scores post with `week`, and the board's "This week" tab shows that week's city scores. Normal games keep the browser's random numbers.
- **Recruiting.** The Team panel is always open on the month plan, with the full staff list open underneath the Recruit line: every role with its description, cost, how many are in post, and Recruit (with its advert cost), Recruit via PCN for GPs, and Let go. `hireNeeds()` marks the roles the practice is short of ("Short": reception short, or not enough appointments) and says why. Once an advert is out, `hireBtns()` replaces Recruit with "1 advert out", Withdraw and a deliberate "+1 more", and the `hire` handler ignores a repeat of the same hire within 0.7 s, so a double tap never places two adverts. A "Recruit staff ↓" link under the month name jumps there.
- **Helping new players.** In April the Locum section sits closed under "More options". "Suggest a plan" (`suggestPlan()`) sets sessions, cover, drawings and a project, and "Bev's plan" (`UI.suggest`) lists each with its reason in a panel under the button that stays until closed or the month changes. Bev scores every project against the practice's needs (low Team, Safety, Patients or You, the inbox, rooms, open adverts, an overdraft, QOF behind, CQC season from September to December) with modest defaults (the online front door, a quiet month), and marks down whatever was done last month or twice in the last three (`S.projHist`), so she rarely repeats herself. The city (brutal) has no Suggest button. The month report ends with a big "Plan May →" (Enter does the same) and, under it, a smaller "Or keep this plan and start May" (`nextgo`). It also has your average week so far this year (`S.hoursTotal`) against the 48-hour Working Time Regulations limit, which doesn't cover self-employed partners, a "What's driving the practice" panel (the three biggest pulls from `targets()`), and delayed consequences say which card, month and choice they came from. From October, a warning box appears when You is heading below 42 before the winter.
- **Projects report back.** `monthEnd` measures what the month's project did (`diffSnap` around its effects, plus rooms, demand and adverts) and `projResult()` writes one plain sentence per project, for example "QOF up 5 points to 11%" or "the inbox fell by 170 items". The report shows it first, as "This month's project" with its effect chips, and a skipped quiet month carries it into the "last month" panel.
- **Toasts** are cards, not pills, stay up for about 4 seconds plus a little per word (tap to dismiss), and sit above the Start bar on phones.
- **The look.** Every card shows the speaker's silhouette, framed in their colour. On the title screen the player picks a silhouette, a colour and a name (the dice button rolls a surname); these are `S.look` and appear as "you", in your room on the surgery front, on the Partners' Board and in the share picture.
- **The opening.** A new game (and the weekly challenge) opens on the April plan with the surgery front dark (`UI.intro`, used once, so any re-render skips the rest). The five windows light up in turn (`.lo` blackouts inside `facadeSVG(c, { intro })`), "Wednesday 1 April 2026, 7:59am" fades in and out, and your name is engraved on the brass plate (`brassPlate(true)`). It lasts about 3 seconds, is pure CSS on the existing SVG, isn't used for continue or take-over, and with reduced motion the picture is simply shown finished.
- **The surgery front.** The month plan opens with the practice at night (`facadeSVG`). Each window is a meter: office (Bank), staff room (Team), your room (You), waiting room (Patients), treatment room (Safety). Lights dim as a meter falls, the people inside change (fewer in the staff room, you slumped at your desk, a warning sign in the treatment room, a red letter on Bev's desk when overdrawn), and a queue forms outside when appointments run short, with rain in winter. Tapping a window (`data-act="win"`) shows what is pulling that meter. The brass plate lists the partners and strikes through those who left. The game-over screen shows the building closed.
- **Endless mode.** After 31 March the year-end screen offers "Carry on: year 2". `continueYear()` keeps the practice, staff, list, cash and meters, resets the accounts and QOF, refreshes the card pool (one-off story arcs, cards marked `once` and last-chance crises stay used), moves everything timed by month back 12 (mods, delayed consequences, new registrations, ICB notices), schedules the calendar again with a `year_new` card, a twist and a new goal. Each extra year (`S.yr`) raises demand by `YEAR_DEMAND` (10%), funding by `YEAR_FUNDING` (2%), staff costs by `YEAR_STAFF` (5%), running costs by `YEAR_RUNNING` (3%) and lowers where You settles by `YEAR_YOU` (7). `monthsServed()` counts the whole run.
- **Drawings follow profit.** In year one the drawings are fixed (`DRAW`). From year two, `continueYear()` sets `S.drawBase` to last year's profit share less pension, a twelfth of it a month (between £3k and £13k), and `drawOf()` scales Lean, Standard and Generous from that. When that's below the old Standard, You settles lower ("Drawings cut to what the practice earns"). The current accounts are settled too: partners who drew more than their share pay it back in from their own pockets (the bank goes up, You takes a hit of up to 15), and a surplus is paid out as far as the bank can spare it (`S.flags.settle`, mentioned on the `year_new` card). This moved later-year game overs from almost all cash to a mix of cash and burnout.
- **Card repetition.** Seen cards come back in later years at a quarter of their weight (`S.ever` counts every card ever played). Cards with `once: 1` (life events such as Mrs Higgins at 90, Sandra retiring, Ellie coming back) never come back. A card's `text` can be an array of variants; `cardText()` shows the next one each time the card comes round.
- **Quiet months.** If a month-end has nothing new (no consequences, hires, departures or endings, no meter moving by 6 or more, nothing below 30, the bank at least £20k inside the overdraft limit, not the first two months of the game, not March), `render()` skips the report (`quietMonth()`) and the next plan opens with a short "last month" panel (`S.lastQuiet`). The setting `quick` in `lps-settings-v1` is on by default, and can be turned off in the menu or under Options on the title screen.
- **Contract explainers.** In the suburb and the town, year one has six cards that explain the contract at a GP trainee's level, with the practice's own live figures: May, where the money comes from (the global sum, weighting, the out-of-hours deduction); August, QOF (what a point and 1% are worth here, the aspiration payment and the June balance); September, after Flu Saturday, what an LES is (national enhanced services such as flu at £10.06 a jab, the local LES or LCS an ICB buys, what they bring in, and that they last only as long as the ICB keeps buying; in 40% of games `lcs_cut` then follows in December to February); October, ARRS (this practice's share of the PCN budget and what's claimed); January, drawings (the profit share so far against drawings and pension, and the first Self Assessment bill); February, why be a partner. `teachSchedule()` puts them in `S.sched` from `newGame`, so each takes one of that month's random slots. They're on by default (`teach` in `lps-settings-v1`, "Explain the contract as you go" under Options and in the menu); switching it mid-game or before continuing a save runs `teachSync()`, which schedules what's left of year one or clears it. The city never gets them. The one asking (`tutor()`, a `who` getter) is Ellie if the registrar is in post, otherwise Tom while he's at the practice (not for "why be a partner?" once he is one), otherwise the registrars on the local training scheme, where Clare has signed you up to teach. The teaching choice costs You and builds Team (or `rep` with the scheme), and its outcome shows a worked table (`tchTable`, from `run()` returning `html`). Teaching pays off quietly: `S.flags.taughtTom` cuts Tom's chance of walking after "Not this year" on `tom_partner` from 50% to 25%, and `taughtEllie` of 2 or more triples the weight of `p_trainee_returns`. No "Comes back later" badge, because the payoff doesn't always exist. The simulator plays with them on.
- **Local services can end.** `lcs_cut` (Nov to Feb, any practice, any year, or scheduled after the LES explainer) is the ICB decommissioning a local service with three months' notice: phlebotomy, then wound care, then ECGs (`LCS_LIST`), worth 35%, 25% and 15% of the enhanced-services income (our estimate). `lcsCut()` adds a permanent mod with `esCut`, which `calc()` takes off `inc.es` once it starts, and the planner's enhanced services line names what the ICB decommissioned. Stopping the work costs Patients and reputation, carrying on unfunded costs Team and You, and pushing back with the LMC is a 40% gamble that the ICB keeps it another year. Once all three have gone, the card stops appearing.
- **Harder mini-games later.** `miniDur()` takes 8% off the 45 seconds each year (never below two thirds), and `miniPen()` adds half a second to the wrong-answer penalty each year (up to 4 seconds).
- **Take over the practice.** After a game over, "Take over →" (`takeOver()`) brings in a new partner with a rolled name and look, where the last one fell: same staff, list, cash and month, with just enough rescue to reopen (You back to 70, the failed meter to at least 32, ICB notices cleared, crisis cards available again). The old partner goes on the brass plate struck through (`S.lineage`), and a `takeover` card opens the next month. Months are counted per partner from `S.startAt`; `S.gen` counts partners.
- **Pressure.** `pressure()` is years served plus partners fallen plus a half for each meter below 30. Cards with `pmin` are only dealt once pressure reaches it, so later years and struggling practices get harsher cards.
- **The three-year review.** In years 3, 6 and 9 (`S.yr % 3 === 2`) the review card comes in September. Passing needs no meter below 35 and a good average (preparation, CQC rating and the bank count): praise, a £15,000 grant and a lift. A middling result passes with conditions; failing brings a six-month ICB improvement plan.
- **The 8am pace.** An optional 45-second timer per card (`CARD_SECONDS`), off by default, toggled under Options on the title screen and in the menu and stored in `lps-settings-v1`. If it runs out, a random allowed choice is taken (never an exit) with a small penalty to You, Team and Patients (`timeUp()`).
- **The number to beat.** The title, year-end and game-over screens say how long partners on the leaderboard last on average, from the Supabase function `lps_stats()` (migration `lps_stats`, shown once at least 10 runs have months), next to the real figure: partners under 40 in England fell by 17% in 15 months to September 2025 (Institute for Government, `S83`). There is no published average length of a GP partnership; about 6.5% of GPs leave each year.
- **The Partners' Board and the brief.** Every run gets a line on a wooden honours board in this browser (`plaque()`), sorted by months served: silhouette, name, practice and how it ended. The year-end and game-over screens show four numbers (time as a partner, personal best, most fragile and strongest meter), the board and a "Share a picture" button that draws a 1200×675 PNG on a canvas and offers to share or save it. The picture shows the surgery front as it stands (closed after a game over) with the player's silhouette.
- **The title screen.** First-time players (no save and no Partners' Board lines) see a shorter title: the silhouette and colour picker, Options (timer, quiet months, contract explainers) and the weekly challenge fold away.
- **The maker's panel.** `SPONSOR` in `h-ui.js` (name, one line and `url`) shows a panel labelled "From the maker of this game" for Datim-QI (https://datim-qi.uk), the maker's AI quality improvement analyst for GP practice management, on the title screen and the year-end screen (`sponsorHTML()`). It never appears inside cards, is hidden inside the Claude Artifact (framed) and stays hidden while `url` is empty. The link uses `rel="noopener sponsored"` and carries no tracking.
- **Score.** A run is ranked by months served first. The leaderboard's "Longest serving" tab sorts by months, with the best single year as the tie-break, and it's the default once a run passes one year or a second partner has taken over (`runTab()`). "Best year" ranks single years. The year score is labelled "Year score" ("Year 3 score" in later years), and later year-end screens also show months as a partner. The year score is mostly meters, CQC and QOF, plus `clamp(annualK-120, -60, 60) * 0.35` for money and the goal bonus. Sensible play scores about 360 in the suburb, 340 in the town and 240 in the city; random play about 190–200.
- **Hidden relationships.** `S.icb` and `S.rep` (0–100) shape patient satisfaction, recruitment, bids and ICB behaviour. The report explains them.
- **Money timing.** The global sum is paid on the weighted list. QOF pays 80% of last year's value monthly, and the balance for what was achieved falls due at the end of the first quarter of the next financial year, so by 30 June (SFE 2026, Section 6). The partners' pension contributions are paid monthly on top of drawings, and personal tax is shown at the end.

### Event format

Event fields:

- `id`, `who` (a `CAST` key), `title`, `text` (string or function)
- `tag`: `real`, `rule`, `story` or `speculative`
- `src`: `SOURCES` ids
- `info`: the "What's real here?" explainer (a blank line, `\n\n`, starts a new paragraph)
- `cond()`, `months[]`, `w` (weight, number or function)
- `arc` (only appears when scheduled)
- `rep` and `max` (repeatable)
- `kind: 'mini'` with `game`
- `after()`, which runs after any choice
- `choices[]`

Choice fields:

- `t` (label, string or function), `fx` (object or function), `o` (outcome, string or function)
- `later[]`, delayed consequences for the main outcome
- `alt: {p, fx, o, run}`, a gamble that replaces the main outcome with probability `p`
- `need()` and `why`, which disable the choice
- `run()` for custom logic. It may return `{o, html}`.
- `play: 1`, which starts the mini-game

`fx` keys:

- `patients`, `team`, `you`, `safety` (clamped 0–100)
- `cash` (£k, counts as profit or loss), `capital` (£k, moves the bank without touching profit)
- `qof` (%; gains shrink near 100), `inbox`, `list`
- `demand` and `admin` (persistent % modifiers)
- `rooms`, `okoye` (Nadia's risk of leaving), `icb`, `rep`
- `aim: {meter: n}`, a lasting shift in where a meter settles
- `staff: {role: n}`, `flags: {}`
- `sched: [[id, monthsFromNow]]`
- `mod: {id, label, months, at, fx, capAdd, capMul, demand, rooms, away, aim, hours}`
- `later: [...]`

Text placeholders: `{surgery}`, `{place}`, `{paper}`, `{name}`, `{qof}`, `{inbox}`, `{list}`.

### Writing rules

These come from the scoping work behind this game.

- Real rules and numbers; fictional people, practices and companies. No named politicians.
- Humour punches up at systems and paperwork, never at patients or reception staff.
- Where the BMA and the government disagree, show both framings.
- Clinical content stays generic. The mini-games say they are not clinical guidance.
- Every choice should cost something. A choice that beats the others on every meter is only allowed when it teaches a real rule (`homeless`: registration needs no ID or address). Choices with a clear upside get a gamble (`alt`) or a cost in time (`inbox`).
- Any card built on a real figure or rule gets `tag`, `src` and `info`. Future policy is tagged `speculative`.

One-year results barely move: sensible play survives about 100% of suburb and town years and 90% of city years (scores 364, 340 and 241; profit shares £134k, £137k and £118k). But the budget now stretches further as claims outgrow it, so fewer later years end on cash, and sensible endless runs last longer: medians about 70 months (suburb, from 61), 58 (town, from 49) and 21 (city, from 20).
- With the contract explainers (September 2026): they replace five random cards in the suburb's and town's first year with gentler ones, so careless play survives slightly more often (suburb 28% against 24% with them off, town 11% either way: within the noise). Sensible play doesn't change (scores 363 against 360 in the suburb and 333 against 330 in the town, town years with Requires improvement 17% against 20%), and nor do endless medians (60 against 61 months in the suburb, 49 either way in the town).
- With the LES explainer and `lcs_cut` (September 2026): the cancellation comes in about 45% of the suburb's and town's first years (the explainer's 40%, plus the random draw) and about 7% of other years. It costs the town about £9,600 a year for phlebotomy, and changes little: sensible play survives about 99% of suburb and town years (scores 362 and 333) and 90% of city years, and endless medians stay about 61 months (suburb), 49 (town) and 19 (city).
- With the ANP (September 2026): the simulator's sensible player now hires one advanced nurse practitioner when appointments are short (within the PCN budget, or when the bank is £60k above the overdraft limit). One ANP lifts year-end patients by about 5 points in the suburb and town and cuts sensible town years with Requires improvement from about 35% to about 19%. In the city it costs the practice about £8k of profit share, because the budget is already spent. Endless medians: about 61 months (suburb), 50 (town), 19 (city); the supervision hours add up over the years.
- After situational choices, the seasons and the summer crunch (September 2026): careless play survives less (about 27% suburb, 9% town), sensible play still survives but about a third of sensible town years get Requires improvement. The city was eased to compensate: starting meters 48/50/66/50 and `accessLine: 15`. Game overs still cluster in December to March, because a failing meter takes six to eight months to reach zero (`DRIFT`); a faster drift spread them only slightly and made the city far harder, so it was left. Endless medians: about 72 months (suburb), 58 (town), 18 (city).
- The suburb and town were made harder in September 2026 (after the 30 cards in `f7-events9.js`): suburb demand 0.097 contacts per patient a week, £50k in the bank against a £65k overdraft, starting meters 54/60/68/58, recruitment 1.0, `turnover: 0.04`; town demand 0.102, £30k against £75k, starting meters 48/52/64/52, recruitment 0.9, `turnover: 0.07`. Each also has a steady drag on where You settles (`youDrag` 4 and 6, with the reason in `youDragWhy`; the city keeps its interpreter line). Sensible play still survives the year, but ends with patients about 51 (suburb) and 43 (town), and about 15% of sensible town years get Requires improvement. Endless medians: about 71 months (suburb), 59 (town), 20 (city).
- After ARRS became a budget (September 2026): the city starts with £226k of its £276k budget committed (£246k before the DES maximums), so extra clinicians there mostly come at the practice's expense. Sensible city play pays for them when the bank allows, which keeps survival about 93% but cuts the profit share to about £121k. The simulator's sensible player recruits over budget only when the bank is £60k above the overdraft limit.
- Burnout in January and February is the most common game over.
- Random play in the town still takes a slightly bigger profit share than sensible play (about £165k against £155k), because the sensible player pays for locums. That's realistic; the score rewards the quality instead.
- The city was rebalanced in September 2026: it starts with a care coordinator and a social prescriber, £40k in the bank against a £110k overdraft, lower overheads and slightly lower demand. It also carries a small extra drag on You. Sensible play now ends with patients around 39, mostly Good from CQC (about a third Requires improvement) and the bank within its overdraft.
- Random-play survival moves by about 5 points between runs.
- The city must be able to beat a sensible player. With `accessLine: 16`, about 5% of sensible city years end with the ICB terminating the contract, mostly in February or March.
- The city was made harder again: demand 0.104 contacts per patient a week (deprived areas consult more), £25k in the bank against a £95k overdraft, lower starting meters, recruitment at 0.7 of the town's success rate, and `turnover: 0.14`. That's a 14% monthly chance that a receptionist, nurse or HCA leaves regardless of morale (`incidents()`). Sensible play survives, but most years end "Survived. Technically.", with patients around 18, 80% Requires improvement and 12% Inadequate.
- The city is under-doctored on purpose. `gpCap: 3000` stops salaried GP recruitment beyond one full-time GP per 3,000 patients (`gpHeadroom()`). That's like the worst-covered parts of Kent; the worst whole ICB, North West London, is about 1 per 2,750. Your own sessions count as one full-time GP, so they never block a hire. The city starts at about 1 per 2,800, already past the cap, so no salaried GP can be recruited even after one leaves, and partnership adverts rarely find anyone. The salaried GP row also has "Recruit via PCN" (`S.vac.arrsgp`): the same £1,500 advert, a slightly wider pool (1.25 times the salaried hire rate, because since 2026/27 any GP not employed in the PCN in the last 12 months can be claimed), and on success a salaried GP counted in `S.arrsGP`, paid from the ARRS budget. Open PCN adverts count against the budget and the GP cap. The Recruit button still works there: the advert costs £1,500 and runs, but while `gpHeadroom()` (which counts open adverts) is below zero nobody applies, and each month-end reports one of the `NO_GP_REPLIES`. Locums are capped at 4 sessions a week there (`locumMax`). Sensible play still survives, but ends with patients around 27 and mostly Requires improvement from CQC.
- ARRS is a budget, not a headcount. The PCN gets `P.arrs` = £27.668 per weighted patient a year (2026/27); the practice's share (`arrsBudget()`, about £203k suburb, £227k town, £276k city) pays for roles at `ROLES[r].claim`: each role's 2026/27 national maximum outside London from the Network Contract DES specification (`S4`), which covers actual salary plus employer NI and pension, and the game claims each post at that maximum. Table 2: £71,725 for a clinical pharmacist or first contact physio (Band 7 to 8a), £69,515 for a community paramedic (Band 7), £46,447 for a social prescribing link worker (up to Band 5), £38,739 for a care coordinator or GP assistant (Band 4). Mental health practitioners use Table 3b (£69,515 at Band 7, funded fully by the PCN; the first MHPs are often funded half and half with the mental health trust under Table 3a, which the game doesn't model). The advanced nurse practitioner (`anp`) is claimed at £78,534, the maximum for a Band 8a advanced practitioner; it offers 80 same-day appointments a week (longer appointments than a GP's) and some inbox work, books 9 room sessions, adds 2 hours a week of GP supervision to your own hours from the first one, is hard to recruit (`hire: 0.35`), and isn't limited by the city's GP cap, so it's the city's way round the GP shortage. ANPs count as nurses in "How you compare with England". Old saves get `staff.anp = 0` in `loadSave()`. Open adverts count as committed (`arrsLeft()`). Recruiting beyond the budget is allowed, but the practice pays the excess (`cost.arrs`, shown as "Additional roles over the PCN budget"). In later years the budget grows with `YEAR_FUNDING` and claims with `YEAR_STAFF`, so it buys less each year. Since 2026/27 the DES also lets PCNs claim practice nurses (£46,447 new to general practice, £57,114 experienced), except nurses who held a post in the PCN in the last 12 months; the game still pays for nurses from the practice. The maximums change every April: check Table 2 of the new specification.
- Staffing is calibrated to the England workforce figures for August 2026 (per 10,000 patients: about 4.6 fully qualified GPs, 2.6 nurses, 2.9 other practice clinical staff and 12.3 admin and reception staff). The Team panel's "How you compare with England" shows the player's practice against these averages (`BENCH` and `benchmark()`). Receptionists are needed at 1 per 1,600 patients.
- Rooms are booked by the session. Each consulting room gives 9 sessions a week (`ROOM_SESSIONS`). `ROLES[r].room` is the room sessions a role books each week: GPs one per clinical session, nurses 8, pharmacists and paramedics 4. Receptionists, care coordinators, social prescribers and GP assistants book none. Starting rooms: suburb 7, town 7, city 8. Nine, not ten, because a room has ten core half-days a week (Monday to Friday mornings and afternoons), less one for double-bookings, cleaning and meetings. The one-off project `meetingroom` (also a choice on the rooms card) adds a room for £4,000.
- Evening and Saturday overtime clinics (`plan.extra`, 0 to `OT_MAX` = 4 a week): your own staff at about £320 a session (`OT_SESSION`) for 12 appointments (`OT_APPTS`), no room needed because they're outside core hours, but each weekly session lowers where Team settles by 1.5. Cheaper than locums (£471 for 14 appointments, no paperwork done: £100 an hour plus 14.38% employer pension on the pensionable 90% of the fee).
- A strategy test with the simulator (town, sensible play): filling the ARRS cap instead of hiring a salaried GP raises the profit share by about £10k but costs about 10 points of patient satisfaction. A third nurse helps patients and the city's CQC rating most for little money. Skipping ARRS costs about £10k.
- The real 2024/25 average partner profit was £164,200.
- Endless mode (`node last-partner-standing/tools/simulate.mjs 200 all smart endless`, up to 10 years, after the long-haul cards and the three-year review): sensible play lasts a median of about 71 months in the suburb and 56 in the town (after the suburb and town were made harder; about 80 and 72 before), ending about 60% by burnout and 40% by the bank, and about 20 months in the city, mostly ending with the ICB (after drawings began to follow profit, September 2026; before that it was about 40 months, almost always the bank). Random play lasts about a year. The simulator treats the new merger and sale cards (`p_merger_again`, `p_apex_again`) as exits it avoids.
